# MetaOntic Media

**让创意成为作品 · Turn Ideas into Media**

MetaOntic Media 是面向 DeepSeek Harness（DSH）的原生图片与视频创作插件，为普通创作者、自媒体和电商用户提供从想法、提示词到生成结果的创作流程。

在 DSH 对话中描述需求，助手整理创意、提示词和生成参数；确认方案后调用你配置的媒体模型，将结果保存到本地，并保留任务与素材记录。

## 主要能力

| 方向 | 能力 |
|---|---|
| 图片创作 | 文生图、参考图生成与图片编辑，具体取决于模型支持 |
| 视频创作 | 文生视频、图生视频与首尾帧生成，时长、画幅和分辨率由模型能力决定 |
| 创意与提示词 | 需求解析、创意增强、图片与视频提示词优化，也可只输出提示词 |
| 模型管理 | 服务商配置、手动添加模型、能力配置、默认模型选择，以及渠道支持时的模型列表同步和非生成连接测试 |
| 任务管理 | 查看历史、查询进度、恢复查询与下载；提交结果不确定时避免盲目重发 |
| 素材管理 | 导入指定参考文件、保存生成结果、查看本地素材及确认后删除 |
| 用量记录 | 查看媒体调用记录与渠道返回的已知费用；未知费用保持未知 |

插件支持自定义服务商，MetaOntic AI / New API 可作为接入渠道。文本创作使用 DSH 当前会话模型，图片和视频分别使用插件配置的媒体模型。

## 开始使用

1. 在 DSH 中安装并启用插件，打开 **MetaOntic Media → 设置**。
2. 添加服务商，填写 API 地址和凭据引用。密钥使用环境变量，设置页填写如 `env:MEDIA_API_KEY` 的引用。
3. 添加图片或视频模型，填写真实上游模型 ID，核对其能力后启用。视频接口还需配置渠道已核验的提交、查询协议。
4. 分别选择默认图片、视频模型，保存设置。
5. 回到对话中描述需求，查看方案并确认生成。

例如：

> 生成一张横屏乡村风景图，清晨薄雾、暖色阳光，先给我看方案。

> 用我指定的参考图片生成一段 5 秒视频，保持主体外观一致。

> 只优化这段视频提示词，不生成媒体。

> 查看之前的生成任务，继续查询并下载结果。

生成前通过 DSH 原生交互确认模型、参数、参考素材发送范围和可获得的费用信息。仅优化提示词不会调用媒体生成接口。文件保存完成后，可获得本地结果路径。

## 数据作用域

设置页提供三种模式：

| 模式 | 适用方式 |
|---|---|
| 全局共享（默认） | 不同会话共用创作记录 |
| 按项目隔离 | 按宿主工作目录分别管理创作数据 |
| 按会话隔离 | 每个会话分别管理创作数据 |

作用域隔离草稿、任务、素材和用量记录；服务商与模型配置共享。切换模式不会自动迁移或删除历史数据，切回原模式可继续访问。此隔离仅适用于插件自身的数据管理。

## 任务与费用

媒体生成按所接渠道实际规则计费。费用无法获取时会标记为未知；模型、参数或服务商变化后需要重新确认。

查询和恢复不会重新提交生成请求。下载失败可单独恢复下载；明确生成失败后再次提交，需要重新确认。暂停本地轮询不代表远端任务已取消或费用已退还，宿主退出期间也不承诺后台持续运行。

## 安装与开发

当前 npm `1.0.0` 是早期占位包，本地开发版本请从源码构建安装：

```sh
npm ci
npm test
npm run typecheck
npm pack
dsh plugin --profile desktop add /absolute/path/dsh-metaontic-media-1.0.0.tgz
```

安装后重新加载 DSH。默认数据目录为 `~/.dsh/dsh-metaontic-media`，可在设置中调整。

当前已进行离线单元测试、模拟 HTTP 生成链路测试和本地安装。真实图片、视频渠道及宿主完整端到端验收仍需使用已授权的渠道、密钥和预算完成。

产品与技术方案见 [V1 原生插件设计文档](dsh-metaontic-media-v1-native-r3.md)，宿主接入说明见 [集成记录](docs/host-integration.md)。
